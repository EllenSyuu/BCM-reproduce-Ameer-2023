# Data and publication boundary

This is an independent, non-official reproduction project. It is not the original UNESCO/UIS/GEMR implementation and must not be presented as official estimates.

The public repository contains source code, method documentation, synthetic examples, and high-level provenance only. Restricted data, internal extracts, credentials, personal information, private correspondence, unpublished estimates, and copyrighted reference papers are not public project contents.

The repository's data directories and internal working documents are excluded from version control. Public readers should obtain external data directly from its authoritative source and follow that source's access and licence terms.
