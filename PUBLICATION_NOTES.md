# Public repository release notes

This project is an independent, non-official reproduction attempt of published
UNESCO Institute for Statistics / Global Education Monitoring Report model
descriptions. It is not the original implementation, is not endorsed by UNESCO,
UIS, or the paper authors, and should not be presented as an official UIS model.

## Data and licensing

Internal, restricted, confidential, or received-under-terms data must not be
committed to the public repository. The `.gitignore` excludes raw and processed
data, local model outputs, internal working documents, and the reference-paper
PDFs. Public users should obtain public data directly from its authoritative
source and comply with its terms of use.

The repository should contain code, documentation of methods and decisions, and
small synthetic examples only. Synthetic examples must be clearly labelled and
must not be derived from confidential records.

## Reproduction scope

The current workstream targets the SDG 4.1.4 out-of-school-rate cohort model.
The separate SDG 4.1.2 completion-rate / ABCR workstream is planned but is not
part of the current implementation.

## Before publishing

Run a clean-tree review and inspect every staged file. Confirm that no internal
data, personal information, credentials, tokens, unpublished results, or
copyrighted papers are included. Do not publish until the target repository's
visibility and license have been deliberately selected.
