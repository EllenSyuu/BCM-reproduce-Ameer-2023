# Public project status

**Last reviewed:** 13 October 2026  
**Scope:** SDG 4.1.4 out-of-school-rate cohort model

## Executive status

The project has moved beyond a blank scaffold: the repository structure, public-data acquisition path, harmonisation architecture, equation-level model reference, and NumPyro/JAX execution path are in place and have been exercised on synthetic or permitted local inputs. It is not yet a complete empirical reproduction because the raw administrative enrolment input is restricted and final source-vintage alignment is still being resolved.

## Capability matrix

| Capability | State | Public claim |
|---|---|---|
| Data acquisition design | Ready | The pipeline is organised around authoritative provenance. |
| Single-age population preparation | Working | Public denominators can be prepared locally. |
| Administrative harmonisation | Logic implemented | Exclusion logic is implemented; production coverage depends on authorised input. |
| Survey/census harmonisation | In progress | Multiple source families can map to a shared schema, subject to access and licence. |
| Probabilistic model | Working on synthetic data | The model translation is executable and testable. |
| Full-scale real-data MCMC | Pending | Requires complete approved input and a compute plan. |
| External validation | Partial / planned | Validation targets are defined; final comparison is pending. |

## What is missing for a complete reproduction

- authorised raw administrative enrolment counts at the required granularity;
- final documented source-vintage and country-coverage decisions;
- complete compatible survey/census coverage;
- final validation against reported outputs and sensitivity specifications;
- a reviewed release package containing only permitted data or approved aggregates.

## How to read progress claims

- **Implemented** means code exists and is exercised by a test or controlled run.
- **Verified** means a specific check passed; it does not mean the entire paper is reproduced.
- **Available locally** does not mean safe to publish.
- **Complete reproduction** is reserved for a run with required inputs, diagnostics, validation, and documented deviations.

## Update protocol

For each milestone, record the date, change, evidence, and remaining limitation. Keep restricted file names, data values, internal contacts, and access instructions out of this public page.
