# Documentation guide

This folder answers three reader questions: **what is the status, what data are needed, and how is the model implemented?**

| File | Purpose |
|---|---|
| [`status.md`](status.md) | One-page progress summary and remaining gaps. |
| [`data-sources.md`](data-sources.md) | Source roles, provenance, access limits, and compatibility. |
| [`model-notes.md`](model-notes.md) | Statistical translation decisions and known deviations. |

The files beginning with `internal_` are working documents for the authorised local environment. They are not part of the public documentation set.
